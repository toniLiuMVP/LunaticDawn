LD4 魔法 / 特殊攻擊資料庫（66 個魔法 / 89 遊戲繁中名 / 5 筆 NPC 交換表 / 1 個官方連結）
來源：日本玩家製作的社群工具神之眼 1.1（2001，原作者 D-SKULL）的定義檔 ld4navi.def，Shift-JIS 日文資料（非 ARTDINK 官方；定義檔內附 ARTDINK 官方網站連結）。
「遊戲繁中名」tab：89 個遊戲內繁體中文魔法 / 特殊攻擊名稱（玩家戰鬥時可見的事實層資料），從 LD4.exe 直接提取。跟上方日文資料是兩個獨立來源，日文 def 含屬性 / MP / 威力等數值，繁中名是遊戲本身的稱呼。
「NPC 交換表」tab：定義檔第二張清單「イモータルの要求/見返りアイテム」。它描述的是跟 NPC イモータル 交換物品的機制，不是可接的任務：共 5 筆，第 1 筆是規則說明（交換次數增加友好度、友好度在由家族成員接手時會繼承等），其餘 4 筆是「非裝備 / 武器 / 防具 / 特殊」四類物品名單（日文物品名）。定義檔另有一張 4 筆的「ＬＧＤ祭壇變化」繁中清單（同組物品之間的變化），已收進 ld4_godseye_def.json，本頁沒有顯示。
跨平台：神之眼 ld4navi.exe 是 Windows 程式，而且是依日文版遊戲寫死記憶體與存檔位置的工具，無法直接讀取繁中版。本頁直接 parse .def 純文字，0 EXE 依賴 + 跨 Mac/Win/手機。
合併版：本資料跟「道具大全」「怪物大全」（LunaticConsortia 繁中）並置，組成 LD4 完整攻略資料庫。
