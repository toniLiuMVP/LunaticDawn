LD4 道具資料庫（630 筆道具，含類別 / 價格 / 附加魔法 / 9 屬性 · 239 筆道具簡名列表）

來源：LunaticConsortia 2007 IDBIG5.dat / LGDBIG5.dat（Big5 純文字資料）的事實層數值：道具名、類別、價格、附加魔法、9 屬性數值、原檔的「出現」欄與合成方法。
跨平台：純 HTML/CSS/JS，Mac / Windows / iPad / Android 瀏覽器都能用，無需安裝 LunaticConsortia.exe（VC6 + MFC42）。
合成方法怎麼看：有配方的道具卡片下方有可展開的「合成方法」。「材料 + 材料 = 此道具」是這個道具怎麼做出來；「此道具 + 材料 = 成品」是這個道具能拿來做什麼。原檔用 + 與 = 表示，本站把每一條配方跟另一端道具的紀錄逐條對照過，兩端全部吻合。部分配方前有 ◆：那是原檔作者自訂的造字記號（本站以 ◆ 代替），意義未確認。
合規：本頁只顯示事實層（道具名、分類、價格、屬性數值與合成方法），不收錄道具的風味說明短文。LunaticConsortia 原始工具的壓縮檔見檔案庫。
