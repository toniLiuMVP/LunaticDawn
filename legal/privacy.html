本站不收集你的任何個人資料。

  • ⚠️ 例外只有俠客遊 IV 存檔修改器(詳見下方 1.5):(1) 用瀏覽器的 localStorage 記住你自己設定的欄位與套餐;(2) 離線快取修改器頁面;(3) 你按下「連線 Live Bridge」時才連到你自己電腦上的 bridge 程式。這些資料只存在你自己的電腦上，不會傳給任何人，也不是 cookie。

本站為 toni 維護的非營利數位文化保存專案,純靜態 HTML+CSS+JS 託管於 GitHub Pages。

[ 1. 本站運作模式 ]

「吟遊詩人的傳說 · 俠客遊」(https://toniliumvp.github.io/LunaticDawn/)是 100% 靜態網站,所有頁面為預先產生的 HTML 檔案,沒有任何伺服器端程式碼(無 PHP / Node / Python 後端)。

瀏覽本站時,你的瀏覽器只跟 GitHub Pages CDN(GitHub 提供的靜態檔案 host)通訊,本站沒有自己的伺服器。你主動點擊 Steam、Google Drive、GitHub、論壇等外部連結後,瀏覽器會與該外部服務通訊(見第 4 節);在俠客遊 IV 存檔修改器按下「連線 Live Bridge」時,則會連到你自己電腦上的 bridge 程式(見 1.5)。

[ 1.5 本機儲存、離線快取與本機連線 ]

本站不使用 cookie，但俠客遊 IV 存檔修改器（luna4/savedata-viewer.html）會用瀏覽器內建的 localStorage 保存三項你自己建立的設定，讓你下次打開不用重設：

  • ld4_custom_fields_v1，你自己新增的存檔欄位（位址 / 編碼 / 名稱）
  • ld4_ram_fields_v1，即時記憶體模式的欄位清單
  • ld4_presets_v1，你自己儲存的數值套餐

這三項的性質：

  • 只存在你這台裝置的這個瀏覽器裡，不會上傳、不會同步，toni 看不到也拿不到
  • 內容是你自己輸入的數字與名稱，不含任何個人身分資料
  • 屬於「功能性儲存」（functional storage），是你主動使用該功能所必需，不需同意橫幅
  • 隨時可清除：用瀏覽器的「清除網站資料」，或在修改器頁面上刪除你建立的欄位與套餐

離線快取:開啟這個修改器時,它會安裝 Service Worker,預先快取修改器頁、manifest 與列舉資料表;之後也會快取 luna4/ 頁面所要求的同源網頁與靜態資源(包括共用的樣式與字型),讓你離線也能打開。快取只存在你的瀏覽器,可用「清除網站資料」移除。

本機連線:修改器的 Live Bridge 是進階功能,只有在你按下「連線 Live Bridge」時,瀏覽器才會連到 127.0.0.1:8765,也就是你自己電腦上另外執行的 bridge 程式,不會連到任何外部伺服器。新版 Chrome 與 Edge 會先詢問你是否允許。

本站其他所有頁面都不寫入任何本機儲存,也不安裝 Service Worker。

[ 2. 你訪問本站時會發生什麼 ]

GitHub Pages 端(GitHub 平台,非本站可控):

  • GitHub 會為了安全目的記錄並保存訪客的 IP 位址(不論訪客是否登入 GitHub;這是 GitHub Pages 的平台做法,不是本站可以關閉的設定)
  • 詳見 GitHub Pages 文件的資料收集段落與 GitHub 平台隱私政策

你的瀏覽器端:

  • 下載本站 HTML / CSS / JS / 字型 / 圖片，所有資源都託管在 GitHub Pages,無第三方 CDN(我們把 Google Fonts 本地化了,正是為了不洩漏訪客 IP 給 Google)
  • 存檔修改器頁面:你上傳的 .SAV 檔完全在你的瀏覽器內處理,不會上傳到任何伺服器(本站根本沒有伺服器)

  • 不會分享給第三方

[ 4. 外部連結 ]

本站含多個外部連結:

  • Steam 商店(導流給 ARTDINK 正版購買):點擊連結會跳到 Steam,本站不參與分潤
  • Google Drive(toni 收藏的歷史檔案下載):點擊會跳到 Google Drive
  • GitHub(本站原始碼 + Issues):點擊會跳到 GitHub
  • 巴哈姆特 / PTT / 第三方論壇(歷史紀錄連結)

點擊外部連結後,你的瀏覽器跟對方網站直接通訊,本站不會記錄你點了什麼。你跳到的網站有他們自己的隱私政策,請自行閱讀。

本站以新分頁開啟的外部連結均加 rel="noopener",防止新分頁取得 window.opener 引用(資安最佳實踐)。
