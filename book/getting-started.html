[ 這頁的依據 ]

這頁依本站收錄的 1998 年 BBS 社群攻略整理,主要是 新手起步指南 與 任務篇。社群攻略是玩家當年的實測經驗,不是官方資料;沒有出處的說法一律不寫。俠客遊 II 的系統不能直接套用到未來之書:例如俠客遊 II 的物理、元素、神聖、暗黑、精靈五系魔法,在未來之書的攻略裡完全沒有出現,未來之書的魔法屬性是秩序、混亂、善、惡四種。

[ 開局與設定 ]

第一步：執行環境

未來之書是 Windows 時代的作品，主程式 LDE.EXE 是 Windows 執行檔，不是 DOS 遊戲，DOSBox 不適用（俠客遊 II 才是 DOS，那一套 DOSBox-X 配置不能套到這裡）。在現代 Windows 上要跑，方向是相容性設定而不是 DOS 模擬：

  • 以相容模式執行 LDE.EXE（右鍵 → 內容 → 相容性），或放進 Windows XP 虛擬機
  • Mac / Linux 玩家走 Wine，不是 DOSBox
  • 中文顯示亂碼是另一個獨立問題，社群的 LDE.EXE 十六進位修法收錄在編碼與亂碼 FAQ

※ 這裡不給逐步教學，是因為 toni 手上沒有在現代 Windows 完整驗證過的流程。與其給一份沒驗過的步驟，先老實標明「DOSBox 不適用、方向在相容性設定」。

第二步：創造世界與人物

攻略作者的流程是先創造世界,再創造人物:

  • 創造世界:剛灌完遊戲的第一次,不要改動善惡、秩序混亂、戰士魔法的比重,保持原始設定,迷宮位置等資料就會和攻略作者提供的一樣。
  • 年紀與職業:作者的經驗是,剛開始選年紀大、戰士型的人物比較容易存活,但後期年紀小、魔法師型的人物比較強。
  • 出生國:作者建議選地圖右上角灣岸都市所在的那一國。一開始買不起一萬元的通行證,只能在國內送貨,而那個平原國家旅行時間短、旅費便宜,比較好存錢。
  • 性別:作者建議剛開始選男性,因為他觀察到女性對結婚沒有主動權。
  • 姓名、稱號、生日:這三項都可以輸入。隱藏角色密技就是靠特定姓名加生日觸發,見隱藏角色密技。

作者自己測試時的人物是「彬彬有禮的 郭勺光」,16 歲、男、魔法師、中津國(善之國)。這只是他的示範,不是推薦配置。

第三步：視窗與設定

  • 視窗:視隊友人數安排,戰鬥時最好看得到 HP / MP 與人像下面的中毒等狀態,迷宮中看得到整個地圖,城市中看得到知名度等數值,訓練前看得到累積經驗的星星亮度。
  • 設定:習慣之後,遊戲速度可以調到最快,訊息速度也調最快或關掉,魔法動畫看過也可以關。損血的數字建議先觀察一陣子再關。

※ 想體驗「神級裝備」可以用隱藏角色密技,但建議先正常玩通關再試。

[ 這個作品的基本設計(依社群攻略) ]

世界與屬性

  • 四種魔法屬性:秩序、混亂、善、惡,四個國家各守護一種。作者形容秩序之國像羅馬(國王象徵物是王冠)、混亂之國像中東的中世紀國家(蘇丹寶石)、善之國像中國(玉璽)、惡之國像日本(大將軍印)。這是玩家的聯想,不是官方設定。
  • 屬性會變:常做「壞事」惡屬性就增加,反之亦然;也可以到寺院捐錢買屬性。魔法屬性會影響施法威力、別人對你的好感,甚至整個世界的消長。
  • 基本屬性四種:力量、知性、敏捷、魅力。要先累積經驗,再到訓練所花兩個星期與金錢才能真正提升;另外還有各地的知名度,主要靠完成旅舍任務提升(打倒大魔王洞窟裡的魔王,知名度會一口氣大漲)。

任務與目標

  • 旅舍任務共 12 種:送貨、購買、搶奪、護衛、暗殺、綁架、援救、鎮壓、探索、奪回、報仇、走私。這些都是支線任務,完成會影響當地知名度、經驗與魔法屬性。作者還拿這一代跟他玩過的前一代比較,說前一代是每間商店都可能給工作,這一代主要集中在旅舍。
  • 沒有故事大綱:作者說勉強算主線的,只有神的試煉與四個國王的試煉。通過神的三個考驗並成長到極點後,可以向神挑戰;另一條路是找一個魔法屬性相符、知名度 100 的首都,在國慶日當天睡在旅舍。兩種事件成功後都會結束遊戲。詳見 神的試煉、國王的試煉。
  • 世代交替:結束遊戲(或退休)後可以留在原世界,改用任何一位滿 16 歲的子女或老婆繼續玩,房子和裡頭的東西都能保留。

隊伍

  • 隊伍最多六人;護衛、援救這類要帶人的任務,目標會暫時算成隊友,組隊前要預留位置。
  • 隊友的評價主要看你的成就:能讓他們賺到錢、基本屬性有成長、知名度夠、生日記得送禮,他們就會跟定你。主動請隊友走路會結下大梁子,死掉的夥伴也要安置(轉生符、寺院復活,或花 3000 元埋葬)。

[ 剛開始怎麼玩(依作者的建議順序) ]

最初階段:先存活、存旅費

  • 新手很脆弱,財力允許就儘量換好的防具(起碼到武器店強化)。藥丸要準備一些,但要留下旅費與訓練的錢。
  • 到旅舍接送貨、購買(要先墊錢)這類簡單任務,比較不會惹上太強的敵人。送貨任務也是初期累積全隊經驗、後來增加知名度的訣竅。
  • 任務要在期限內回旅舍領酬勞,否則酬勞取消、知名度反而下降;送貨超過期限還沒送到,會被當成監守自盜而遭通緝。

錢夠了之後:訓練

  • 作者建議先訓練敏捷度(剛開始逃跑、偷東西、開鎖都最有用),敏捷夠高再訓練力量以提高 MaxHP,就算是法師也最後再訓練知性。
  • 作者的賺錢方式是偷竊,但偷竊與襲擊都會增加惡與混亂屬性,失手還會被通緝並引來警衛,通緝時間可參考城市警衛篇。作者的說法是,偷得好一下子就能湊到所有國家的通行證和一棟房子。

進入迷宮前

  • 迷宮中不能存檔,進入前先準備好。
  • 照明道具:每間道具店都有賣,四個國家用的東西不同;只要不被陷阱吹熄,出迷宮之前都不會熄滅。
  • 開鎖與陷阱:可以帶鑰匙開門和寶箱,但鑰匙對陷阱無用,所以隊伍裡最好有個敏捷度較高的人,才不會栽在隱形陷阱上。陷阱圖可以讓陷阱現形,必經之路上的陷阱還是得解除。
  • 看地圖:平面地圖比 45 度角的視覺視窗好對位置,走過的部分只會顯示在地圖視窗,幻術牆(牆色較淡的部分)也只有地圖上看得到。
  • 探索、尋人類任務要小心:迷宮怪物等級較高,菜鳥階段不要冒然嘗試。
