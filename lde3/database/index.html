遊戲資料 .dat 檔結構觀察：第三之書的 res 資料夾共有 162 個 .dat 檔（官方更新修正檔 1.1+1.2 另附 card / mon / item 三個子資料夾，內含其中 11 個資料表），包括：
▸ item：ItemNameStr.dat / ItemParam.dat / ItemPropStr.dat
▸ mon：MonsterNameStr.dat / MonsterParam.dat
▸ card：SpCardNameStr.dat / SpCardParam.dat / ItemCardParam.dat / MonsterCardParam.dat / ItemNtoCardI.dat / MonsterNtoCardI.dat

共同 header：byte 0-3 是檔案大小，byte 4-7 是解壓後大小，byte 8-9 是 ASCII 標記「HF」，byte 28-31 重複 byte 4-7 的值。各檔大小隨遊戲版本略有不同。
內容：資料區是 Huffman 壓縮，本站已解開壓縮層；解開之後本站沒有在其中找到道具、怪物、卡片的名稱字串（直接比對、XOR 0x66、XOR 0xFF 三種方式都試過），推定解壓後是數值與索引表，各欄位的意義尚未解讀。解壓後最常見的位元組是 0x66，可能還有第二層編碼，本站未確認。ELF 工具的 ReadMe（1.60 版的版本說明）提到它能解開一部分帶 str 的 .dat，本站未驗證。檔名雖然帶有 NameStr，但道具、怪物、卡片的名稱可以直接從 Lde3.exe 讀出：它們以 Big5 明文內嵌在主程式。本資料庫的「道具列表」與「怪物列表」就是直接讀主程式內的名稱表，不需要解開 .dat。
第三之書 LDE3.EXE 逆向字串字典（810 個有效中文字串，2026 逆向工程提取）

方法：對 Lde3.exe (PE32, 2.5MB) 用 Big5 模式（high byte 0xA1-0xC6）+ ≥4 中文字 + null terminator 過濾，去重後分類。

名稱的法律定位：純名字 / 系統字串字典，字串取自遊戲主程式，屬事實層內容（是否每一條都會出現在遊戲畫面，本站未逐條核對）；名稱屬單字或短詞，一般認為不具或僅有極有限的著作權保護（個案判斷）。本頁的分類與排序是本站整理，不主張其權利。

用途：玩家遇到不熟字串時可在此查詢含義 / 玩家社群核對遊戲系統翻譯。完整 JSON 在 strings.json。
