第三之書 道具列表（215 筆，依 ID 排序）

內容：主程式道具表中的 215 筆道具名稱與 ID，依數值 ID 排序，名稱包含武器、護具、消耗品、卡片及其他道具；各項實際的取得方式與出現的畫面，本站未逐件確認。

ID 與名稱來源：ID 是主程式 Lde3.exe 道具表內每件道具名稱前面的編號（不是連續號碼：第一件短劍是 0，最後一件龜甲是 467）；表的第一格「亂數選擇」（編號 -2）推定是隨機選擇用的特殊項目，不算道具。名稱依 1.2 版主程式，原版與 1.1 版有四件名稱不同（小刀原名匕首、單手戰斧原名戰斧、木棍原名木棒、祭品之杖原名遠古之杖）。編號 422 在主程式裡的字碼是誤植（會顯示成一個俄文字母加「首」），社群道具表同編號為匕首，本站依此寫成匕首（推定）。

用途：玩家撞名 / 翻譯對照 / 收集進度查詢。完整 JSON 在 items.json。

合規說明：道具名稱與 ID 取自主程式道具表，屬事實層內容（各項在遊戲內的取得方式與出現畫面，本站未逐件確認）；名稱屬單字或短詞，一般認為不具或僅有極有限的著作權保護（個案判斷）。
