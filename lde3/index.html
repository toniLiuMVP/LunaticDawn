[ ABOUT ]

Lunatic Dawn: The Third Book (2002) · 俠客遊 Book 三部曲第三作 · 台灣美商藝電代理

第三之書（Lunatic Dawn: The Third Book，簡稱 LDE3）是 2002 年由台灣美商藝電代理發行的俠客遊系列作品，是繼 1998 年未來之書（The Book of Futures）、1999 年前途道標（Passage of The Book）之後的「Book 三部曲」第三作。官方繁體中文版主程式的版本資訊是 1.0.8.2，原版與官方 1.1、1.2 更新檔都標同一個版本號。

本站收錄歷年來社群製作的工具與修正檔，包含 Morrowind 製作的 ELF 工具、kkarthur 的修改器、askacheng 的管理員、anDY & aSKa STUDiO 的流動化啟動器，以及解決 Win98 / XP / Win11 各時代相容性問題的修正檔。

▶ 想直接玩？用 EzPlay 補丁包：自備正版，解壓覆蓋到遊戲資料夾，雙擊啟動檔即玩（Windows / Mac）。

[ INSTALL · 安裝設定 SOP ]

第三之書原版光碟跨 Win98 / XP / Vista / 7 / 8 / 10 / 11 不同時代有不同安裝障礙。另有 EzPlay 補丁包，含 ME 版遊玩及出現試玩版的問題解決，並保護玩家所持有的正版光碟（見 EzPlay 第三之書）。以下是 toni 跨年代維護整理的標準流程：

  1. 遊戲資料夾路徑用簡潔英文，避免中文字 / 空格 / 過深層級。建議：C:\ARTDINK\Lde3\ 或可攜版直接放隨身碟根目錄。
  2. 套用官方 1.2 更新檔，把官方修正檔解壓後複製到遊戲資料夾覆蓋（原版與更新版的版本資訊都標 1.0.8.2，不能用版本號判斷有沒有套用）。
  3. NoCD 化（避免每次都要放光碟），第三之書保護光碟檔解壓後跑，會建立 NoCD 環境。
  4. 解 Win11 / XP / Win98 相容性（如果遇到「試玩版」或「找不到光碟」問題），下載對應系統的登錄檔修正檔解壓後執行。
  5. 輔助工具放遊戲資料夾內執行，這是舊站一直沿用的維護建議；個別工具要放在哪裡、怎麼啟動，以該工具附帶的說明為準。
  6. 登錄檔路徑用雙斜線，若手動編輯登錄檔，路徑必須寫雙斜線，例：
    c:\\Program Files\\ARTDINK\\Lde3\\LDE3.EXE

[ FAQ · 常見問題排除 ]

Q1. 安裝完跑遊戲變成「試玩版」？

原因：登錄檔內遊戲執行檔路徑沒寫對 / 系統升級後路徑失效。
解法：依作業系統下載對應修正檔，lde3reg.zip（通用）/ XP 版 / Win11 版。解壓後執行裡面的 .reg 或 .bat 檔即可。

Q2. 開啟遊戲提示「找不到光碟」？

原因：未套用 NoCD 修正 / 光碟認證機制在新作業系統上失效。
解法：套第三之書保護光碟檔（最新版）或歷史 NoCD 版。

Q3. 想直接攜帶玩不要安裝？

解法：用PortableLde3_tw1082r1.zip 可攜版，解壓即用。適合放隨身碟 / SSD 帶到不同電腦玩。

Q4. 用修改器改完存檔，進遊戲數值沒變？

第三之書採自動儲存，遊戲進行中會經常存檔，結束遊戲時也會存檔（依遊戲附帶的說明檔）。所以要先從選單〔遊戲〕選〔結束〕離開遊戲再改存檔；遊戲還開著就改檔，推定會被遊戲之後的儲存蓋回去。用本站瀏覽器版修改器時，改完要拿下載的檔案取代 usr/lde3s.le3。第三之書修改器 v0.4（kkarthur 製作）的使用方式本站未核實，請以該工具的程式畫面為準。

Q5. 想使用角色管理與事件日期計算工具？

歷史第三之書管理員 1.03 / 1.06 內嵌第三之書包裝封面縮圖，壓縮檔註解另有功能說明與版本修正紀錄。最新版用第三之書管理員 1.0.6（askacheng 製作）。

Q6. 為什麼推薦的工具多是 2007 到 2011 年的社群作品？

第三之書 2002 年發行後，社群工具多半完成於 2007 年到 2011 年之間，例如第三之書修改器 v0.4（2011-10-14）與 ELF v1.62（2011-11-25）。Morrowind / kkarthur / askacheng 等社群開發者貢獻的工具，本站只收錄、整理，沒有逐項實測比較。

[ GAMEPLAY · 玩法心得 ]

⭐ 以下是 toni 跨 20+ 年實玩經驗整理的第三之書玩法重點，純粹基於玩家視角觀察（非攻略書抄錄）：

遊戲節奏

  • 初期建議：第三之書沿用 Lunatic Dawn 系列的開放世界 RPG 設計，沒有強制主線；開局從現成的角色中挑一位當分身（再改名字、稱號與生日），之後自己決定同行的冒險者與探索順序。
  • 練功 vs 委託：跟系列其他作品類似，「接旅店委託 → 完成任務 → 賺錢 → 升級裝備」是最穩定循環。
  • 同行 NPC：找到優秀技能的 NPC 一起冒險，技能熟練度互補比起單機提升明顯。

使用 ELF 工具的時機

  • Morrowind 的 ELF 工具 v1.62：搭配遊戲一起執行的輔助工具，依附帶的 ReadMe，功能有道具儲物空間、陳列室、道具資訊、戰場情報與吟遊詩人的時間修改（本站未逐項實測）。ReadMe 特別提醒買房子時不要關閉 ELF。
  • kkarthur 的修改器 v0.4：Windows 程式，能修改哪些項目本站未核實，請以程式畫面為準，使用前先備份 usr/ 資料夾。
  • 建議順序：先正常玩 → 卡關才用工具，避免一開始就破壞遊戲樂趣。

日期計算器

Morrowind 的「第三之書日期計算器」，依舊版（The3rdbookDATE）附帶的說明，輸入遊戲年份就會顯示該年會發生的事件和發生的地點。說明列出的週期：建國紀念日和王家賣物會每年每國都會出現；天下第一武鬥會每年由四國輪流舉行；最強死鬥會（雙數年）和世界統一卡片大會（單數年）各兩年一次，也是四國輪流舉行；妖精之國在 4 的倍數的年份 3 月 3 日出現。本站沒有逐項實測。

存檔管理（Morrowind 中文化）

Lunatic Dawn 系列傳統有 USER0-USER9 共 10 個存檔位置，但第三之書中切換存檔需要手動覆蓋資料夾。第三之書存檔管理器 解決這問題：

  • 備份多個存檔狀態
  • 切換不同進度（例：一個練功用、一個劇情用）
  • 避免存檔損毀
