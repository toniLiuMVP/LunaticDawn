[ 怪物名稱 ]

遊戲主程式 Lde3.exe 的怪物表共有 75 筆記錄，第 0 筆「亂數」是隨機選擇用的特殊記錄，不算怪物，其後 74 筆是怪物，從「老鼠」排到「恐龍」。本站資料庫照表中順序列出；相近的怪物排在一起（例如「蟑螂 / 蜘蛛 / 毒蜘蛛 / 蝗蟲 / 蠍子」「瓦伊邦 / 死龍 / 紅龍 / 藍龍 / 白龍」）。每筆記錄在名稱之後有一個類別位元欄，74 隻怪物共出現 8 種值，資料庫的怪物列表可以依這個值篩選；各個位元對應哪個分類名稱，本站尚未確認。完整名稱見▸ 第三之書怪物列表。

各怪物的能力數值與出現地點，本站尚未整理。

[ 怪物分類 ]

主程式裡有一組怪物分類名稱（推定）：人類 / 亞人類 / 動物 / 活死人 / 鬼魂 / 魔法生物 / 龍 / 惡魔 / 獸 / 水生。上面提到的類別位元欄與這組名稱如何對應，本站尚未確認；各分類實際影響哪些數值，也尚未確認。

[ 怪物卡片 ]

戰鬥中用卡片魔法給怪物最後一擊，倒下的怪物可以封進 CO-卡片，成為怪物卡片。卡片魔法的用法見▸ 卡片魔法指南。

依遊戲附帶的說明檔（hlp 資料夾）整理。

[ 進迷宮前的準備 ]

  • 迷宮裡一片黑暗，一定要帶燈；燈可能在離開迷宮前就用完，最好多帶幾個。
  • 迷宮裡有上鎖的門、機關、寶箱、階梯與秘密通道，也會有怪物擋路，要打或逃由玩家決定。
  • 要去迷宮時，可以順便接「驅退」「救出」這類委託，同時拿報酬（見▸ 任務系統與冒險指南）。

依遊戲說明檔整理。
