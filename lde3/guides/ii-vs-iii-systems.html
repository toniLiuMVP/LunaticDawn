本頁主題：俠客遊 II（1996，Artdink）與 第三之書（2002，Artdink）核心系統差異對照。差異以遊戲二進位與遊戲附帶的說明檔為準，推定之處另外標明。

特別說明：兩作雖然同系列，但戰鬥系統、屬性系統、整體玩法在第三之書都做了明顯重構。本表幫助 II 的老玩家理解第三之書的學習曲線。

[ 任務 / 委託系統 ]

項目俠客遊 II第三之書
任務類型 15 種（從 LUNA2.EXE 0x40224 提取）：送貨 / 購物 / 護衛 / 探索 / 修行 / 復甦 / 決鬥 / 調查 / 擊退 / 奪回 / 救出 / 強盜 / 暗殺 / 綁架 / 收買 14 個名稱（推定是委託類型名稱）：逃獄 / 通緝 / 討伐 / 試練 / 探索 / 驅退 / 打敵人 / 暗殺 / 奪回 / 強盜 / 走私 / 買東西 / 秘密出口 / 送貨。這 14 個名稱在 Lde3.exe 裡連續出現在「普通結束 / 無法達成 / 達成 / 實行中 / 發生」之後；遊戲說明檔與主程式的委託文字另提到購物、護衛、救出、綁架等委託，所以它們不一定涵蓋第三之書全部的委託種類，總數本站未確認
名稱比對（只比字串同名） II 的 15 個名稱中，與 III 那 14 個名稱同名的有 5 個：探索 / 奪回 / 暗殺 / 強盜 / 送貨；沒有同名的有 10 個：購物 / 護衛 / 修行 / 復甦 / 決鬥 / 調查 / 擊退 / 救出 / 綁架 / 收買。其中購物、護衛、救出、綁架在 III 的說明檔或主程式裡也有對應的委託說明；修行 / 復甦 / 決鬥 / 擊退 / 收買在原版、1.1、1.2 三版主程式都找不到。所以「沒有同名」不等於「III 沒有這類委託」 III 的 14 個名稱中，II 名單沒有同名的有 9 個：逃獄 / 通緝 / 討伐 / 試練 / 驅退 / 打敵人 / 走私 / 買東西 / 秘密出口。「買東西」與「購物」、「驅退」與「擊退」字面不同，是否同一類本站未確認（說明檔把「購物」與「驅退」都當成委託）
名稱同名 字串同名的有 5 個：探索 / 奪回 / 暗殺 / 強盜 / 送貨（II 的 15 個名稱 = 5 個同名 + 10 個沒有同名；III 的 14 個名稱 = 5 個同名 + 9 個沒有同名）。這只是名稱的字面比對，不代表兩作的玩法相同或不同
委託發布 城鎮設施的店主委託（LUNA2.EXE 的委託字串是店主口吻；15 項城鎮設施中沒有酒館或廣場，確切由哪些設施發布本站未逐一確認） 城鎮的酒店（附設旅館）「委託」分頁，達成後回到同一家酒店領報酬（依遊戲說明檔）
事件相關詞彙 無 主程式內有一組事件相關的詞彙：搜索 / 脫獄 / 逃亡 / 被懸賞者 / 護衛 / 救出 / 綁架（是不是事件的子分類、用在哪裡，本站未確認）

[ CO-卡片與連線功能 ]

以下依遊戲附帶的說明檔，以及主程式 Lde3.exe 與卡片程式庫 CoCard.dll（CO-卡片與卡片遊戲用，352 KB）的字串整理：

  • 4 種屬性名稱：黑暗 / 神聖 / 混沌 / 秩序（字串旁邊是「攻擊屬性」），各屬性與卡片的關係本站未確認
  • 支援卡片 vs 攻擊卡片：介面有「請取出支援卡片」「請取出攻擊卡片」兩種提示（推定是卡片遊戲的操作）
  • 世界分享（依說明檔）：玩家的世界資料（說明檔稱為「FIX 世界資料」）可以輸出成網頁，上傳到 ARTDINK 或美商藝電的伺服器，或自己的網頁空間；其他玩家再從寺院的「環節之門」或網頁上的連結進入該世界。試玩版限制清單（Lde3.exe）寫著「ARTDINK 伺服器的處理部份有限制」「FIX 世界的輸出有限制」
  • CoCard.dll 的連線字串：「主機解決」「受信中」「送信中」「接續」「伺服器掛了」等是一般的網路連線狀態與錯誤訊息（其中也有標準網路錯誤碼的文字），光看字串無法判斷是哪個功能在使用。另有 NET / COMPUTER / ONESELF 的玩家類型與「>> From Player%d, Socket%d」這類字串，卡片遊戲有沒有玩家對玩家的連線，本站未確認

第三之書日文版的網路伺服器服務，依 KOMODO Plaza 商品頁已於 2017 年 12 月 11 日終止，且不使用網路服務也能玩到最後；繁體中文版（美商藝電伺服器）現在是否還在運作，本站未查證。俠客遊 III、IV 的次元之門連線見俠客遊 III 與俠客遊 IV 連線方法。

結論：第三之書並非「俠客遊 II 加強版」，能力、技能、魔法、國家與城鎮設施都換了一套。II 的老玩家要適應的重點是魔法改以卡片施放（卡片加 MP，而且只能用放在卡片板上的卡片）。

選擇建議：偏好傳統 RPG 玩法 → II；喜歡收集卡片 → III。

版本選擇：建議套用 1.2 更新檔（國名譯名統一與道具、卡片魔法的改名都在更新檔裡）。
合規說明：本對照表依主程式字串、遊戲附帶說明檔與社群資料整理（屬性名稱 / 任務類型名稱 / 系統機制存在與否 / patch 修正紀錄），各項的來源與確認程度見表內標示，並非每一項都已在遊戲內逐項核對；事實與系統觀察屬思想、系統層面，一般認為不受著作權保護；名稱屬單字或短詞，一般認為不具或僅有極有限的著作權保護（個案判斷）。
