[ 魔法附在卡片上 ]

第三之書的魔法稱為「卡片魔法」，附在 CO-卡片上施放，沒有俠客遊 II 那種依系別到特定設施學習的魔法。遊戲主程式 Lde3.exe 裡找不到「物理系 / 元素系 / 神聖系 / 暗黑系 / 精靈系」「魔法屋」「精靈術屋」這些字串，俠客遊 II 的 58 個法術與召喚獸名稱也都查不到。

  • 施放時要同時消耗卡片與精神力（MP），缺一項就不能用；若施放後 MP 降到 0，施法者會昏倒。
  • 戰鬥中只能使用放在卡片板上的卡片。卡片板放不下的卡片會收進卡片資料夾，需要時要先移到卡片板。
  • 能力值中的智力影響可使用的卡片魔法種類，直覺影響 MP 的成長。

以上依遊戲附帶的說明檔（hlp 資料夾）整理。

[ 四種魔法屬性 ]

世界上有秩序、混沌、聖、黑暗四種魔法屬性，秩序與混沌對立、聖與黑暗對立。各屬性在世界上的強弱會影響卡片魔法的效果，也影響國家之間的勢力。8 個國家各有信仰的神，所屬的屬性如下：

  • 秩序：卡茲赫姆、羅瑪爾
  • 混沌：馬尼卡帕、伊雷儂莫
  • 聖：巴拉克夏、伊塔爾
  • 黑暗：日倭、長唐

依遊戲說明檔的國家表整理。CO-卡片程式庫 CoCard.dll 裡的 4 個屬性名稱（黑暗 / 神聖 / 混沌 / 秩序）見卡片系統詞彙。

[ 取得卡片 ]

  • 寺院購買：低階的魔法卡片在寺院販售。
  • 封印怪物：戰鬥中用卡片魔法給怪物最後一擊，倒下的怪物可以封進 CO-卡片，成為怪物卡片。
  • 道具卡片化：與其他玩家交換道具時，可以選擇把道具卡片化後再收取。

依遊戲說明檔整理。

[ 主程式內的卡片魔法名稱 ]

Lde3.exe 在卡片種類名稱（魔法 / 事件 / 怪物 / 道具等）之前有一張 32 個名稱的表，推定是卡片可附帶的魔法：

召喚之門 / 魔法連結 / 水之力場 / 黑色吐息 / 冰之力場 / 吸取能量 / 反轉陣式 / 毒藥 / 復活 / 完全復原 / 聖之力場 / 治癒狀況 / 恢復力場 / 治癒 / 右旋轉 / 閃光 / 死亡魔咒 / 依弗利特 / 暴風力場 / 大地之力 / 地獄力場 / 迷幻 / 亂數陣式 / 地震 / 宇宙直線 / 消失 / 宇宙力場 / 攻擊的力量 / 空之力場 / 流星攻擊 / 左旋轉 / 鷹隼

上面是官方 1.2 更新檔的版本；1.1 以前的主程式在「消失」的位置是「痛擊」。本站依名稱整理的分組見卡片系統詞彙。
