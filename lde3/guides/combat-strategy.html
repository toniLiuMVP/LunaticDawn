[ 戰鬥指令 ]

戰鬥中每個角色的行動從指令視窗選擇：

  • 攻擊：用裝備的武器攻擊選定的對象；沒有選對象時，由電腦自動決定。
  • 卡片魔法：從卡片板選卡片，再選施法對象。要同時消耗卡片與精神力（MP），缺一項就不能用；若施放後 MP 降到 0，施法者會昏倒（見卡片魔法指南）。
  • 道具：對敵人或同伴使用道具，武器與防具也在可選的範圍內。
  • 防御：選自己就防御自己，選其他角色則挺身保護對方。
  • 必殺技：使用學會的必殺技；還沒學會時不能使用（見第三之書的必殺技）。
  • 指示：對全隊或個人指示戰鬥方法。
  • 逃跑：只有自己的角色會逃走。要全隊一起逃，得用「指示」要求全員逃跑。

「戰鬥設定」可以調整台詞顯示、特殊攻擊的動畫、傷害顯示與台詞顯示時間，也可以打開自動指令輸入（打勾後角色會自動行動，想自己下指令時點一下指令即可暫停）。在選單的戰鬥設定中，輸入時間除了最慢的一檔以外，時間到了還沒下指令，指令會自動決定。

依遊戲附帶的說明檔（hlp 資料夾）整理。

[ 行動順序與隊形 ]

  • 進入戰鬥後，角色依敏捷的高低順序行動。地圖視窗的「行動計器」顯示每位隊員到下次行動前的剩餘時間，歸 0 時就執行排定的行動。
  • 戰鬥中的地圖視窗也顯示陣式：I 到 VI 是隊伍成員的位置，M 是怪物的位置。
  • 隊形要在非戰鬥時用工具條的〔隊列變更〕調整，1 到 9 號格代表戰鬥時的位置；按〔清除〕會從 1 號起依序重排，1 號是自己的角色。
  • 說明檔建議有體力的戰士系排前列、體力少的魔法師系排後列，並提到位置的排列會讓攻擊出現不同的結果。
  • 隊伍含自己最多 6 人。

依遊戲說明檔整理。

[ 影響戰鬥的能力與技能 ]

  • 敏捷：行動順序，以及逃跑與指示的行動時間。
  • 靈巧：使用道具與必殺技的行動時間。
  • 武器技能（劍 / 斧 / 挌鬥 / 弓 / 機械 / 投擲 / 槍 / 棍棒）：攻擊力與攻擊前的時間。
  • 防禦技能：半防禦與完全防禦的發生率。
  • 回避技能：攻擊回避、逃跑與陷阱回避的機率。
  • 道具的數值有攻擊、防禦力、速度、命中與致命一擊，武器另外標示攻擊距離；道具也可能附有魔法屬性。

狀況視窗的「戰鬥力」列出武器攻擊力、武器魔法攻擊力、物理防禦力、魔法防禦力、行動速度、攻擊回避力與魔法攻擊力，可以用來比較裝備前後的差別。

依遊戲說明檔整理。

[ 狀況變化 ]

  • 魔法封閉：無法使用魔法。
  • 浮遊：可以走過地洞陷阱。
  • 麻痺：無法行動。
  • 魅惑：被敵人魅惑，轉而攻擊同伴。
  • 毒：持續受到傷害。
  • 盲目：命中率下降。
  • 攻擊上昇 / 魔力上昇 / 敏捷上昇：暫時提高攻擊力、魔力或敏捷。
  • 完全回避：完全避開攻擊。
  • 暈倒：無法行動，經過一段時間後以 MP 1 醒來。MP 用到 0 也會昏倒。
  • 死亡：無法行動；可以在寺院用復活道具讓隊員復活。

依遊戲說明檔整理。

[ 魔法屬性 ]

世界有秩序、混沌、聖、黑暗四種魔法屬性，世界屬性的強弱會大幅影響卡片魔法的效果。武器與防具也可能附有魔法屬性，寺院可以強化與該城鎮屬性相同的魔力。各國所屬的屬性見卡片魔法指南。

依遊戲說明檔整理。

[ 戰鬥之後 ]

  • 打贏後怪物有時會掉落道具。好幾個隊員都想要同一件時，要以道具為賭注，用卡片遊戲決定歸屬。
  • 用卡片魔法給怪物最後一擊，倒下的怪物可以封進 CO-卡片，成為怪物卡片。
  • 走海路移動遇敵的機率很低，但在船上遇敵時很難逃跑。

依遊戲說明檔整理。

[ 與俠客遊 II 的差別 ]

俠客遊 II 的弱點屬性（炎熱、冷卻等）、戰鬥指令「喊叫」（其下有「解救」等指示）、法術「護盾術」「索敵術」「沈默術」，以及 STM 數值，在第三之書的主程式 Lde3.exe（原版、1.1、1.2 三版）與 CoCard.dll 裡都找不到字串，不能直接套用到第三之書。俠客遊 II 的戰鬥整理見▸ 俠客遊 II 戰鬥策略整合篇，兩作的系統差異見▸ 俠客遊 II vs 第三之書 系統對照。
