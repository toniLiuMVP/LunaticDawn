[ 第一步：環境準備 ]

第三之書是 Win 原生程式（不需 DOSBox），但 2002 年的程式對 Win10 / Win11 有相容性問題。

  1. 安裝路徑：英文簡潔，例 C:\ARTDINK\Lde3\（避免中文 / 空格 / 過深）
  2. 套官方更新檔：官方出過 1.1 與 1.2 兩版更新檔（檔案庫有收），建議套到 1.2。原版與更新後的主程式，版本資訊都標 1.0.8.2，不能用版本號判斷是否已更新。
  3. NoCD 化：套保護光碟檔，避免每次都要放光碟
  4. 登錄檔修正：Win11 套LDE3win11.7z，XP 套Lde3XP.zip

[ 第二步：建立世界與角色 ]

從選單〔遊戲〕選〔新世界〕，開頭動畫的詩結束後，依序設定：

  1. 創造 HOME 世界：不喜歡地形與屬性，可以拉動屬性的滑條再按〔再創造〕（拉過滑條後，要先再創造才能按〔決定〕）。滿意後輸入世界的名字。
  2. 選擇角色：用〔下一步〕〔返回〕瀏覽現成的角色，選一位當作自己的分身。
  3. 稱號、名字、生日與象徵：稱號、名字與生日可以自由修改，象徵（狀況視窗的圖案）用滑條挑選。稱號之後也能從〔設定〕→〔稱號的變更〕修改。

角色的能力有肌力、智力、敏捷、靈巧、直覺、魅力 6 項。依血統不同，成長的界限也不同；8 個國家各有優生能力與優生技能：

  • 卡茲赫姆（秩序）：智力 / 機械
  • 羅瑪爾（秩序）：體力 / 挌鬥
  • 馬尼卡帕（混沌）：魅力 / 棍棒
  • 伊雷儂莫（混沌）：肌力 / 斧
  • 巴拉克夏（聖）：精神 / 弓
  • 伊塔爾（聖）：直覺 / 劍
  • 日倭（黑暗）：靈巧 / 投擲
  • 長唐（黑暗）：敏捷 / 槍

以上依遊戲附帶的說明檔（hlp 資料夾）整理，國家表的寫法照說明檔原樣。俠客遊 II 那種自選性別、家系、種族、職業的角色建立方式，說明檔沒有提到；主程式裡也找不到 II 的種族名稱（小妖精、侏儒、半環、半小妖精）與「雙性」字樣。

[ 跟前作的差異 ]

沿襲前作的設計

  • 開放世界 RPG 結構（無強制主線）
  • 城鎮 + 地下城 + 戰鬥地圖三段式
  • 能力值與技能熟練度的成長（第三之書的能力值改為 6 項，魔法改以卡片施放，差異見系統對照）
  • 在城鎮招募同伴組隊冒險（見同行 NPC 招募流程）

第三之書新增 / 改良

  • Windows 原生程式（不需 DOSBox）
  • 魔法改以 CO-卡片施放，另有卡片遊戲「椎王」（見卡片魔法指南）
  • 環節之門：可以在平行世界之間移動
  • 可以建房子、結婚、生小孩並教育小孩，讓下一代繼續冒險
  • 社群修正檔與工具：本站檔案庫收錄 2002 到 2023 年的版本

[ 剛開始的玩法建議 ]

  • 先收集情報：在城鎮的〔廣場〕與〔酒店〕和其他冒險者談話、聽謠言，並試著〔邀請〕同伴；對方答不答應，要看彼此的屬性與你的魅力。
  • 接委託：在酒店的「委託」分頁接工作。剛出道推薦送貨或購物，一開始不要接驅退怪物的委託；可以同時接好幾件，但要在期限內回到接委託的酒店領報酬（見任務系統與冒險指南）。
  • 排好隊形：找到同伴後，用工具條的〔隊列變更〕排隊形，有體力的戰士系在前、魔法師系在後。
  • 訓練能力：只累積經驗會提升技能，但不會提高能力。經驗與金錢夠了，再去訓練所訓練 6 項能力。訓練所只有大城鎮才有，受訓會佔用好幾天，小心讓委託過期。
  • 進迷宮前：先到道具店準備燈與回復藥。燈可能在離開迷宮前就用完，最好多帶幾個；沒把握時不要一個人進去。去迷宮可以順便接驅退或救出的委託。
  • 移動：走海路花錢但速度快、遇敵機率低，不過在船上遇敵時很難逃跑。

依遊戲說明檔中的「冒險者前輩的來信」與城鎮、迷宮各章整理。
