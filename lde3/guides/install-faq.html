[ 安裝 SOP · 6 步驟 ]

⭐ 跨 Win98 / XP / Vista / 7 / 8 / 10 / 11 不同時代的標準流程：

  1. 遊戲資料夾路徑簡潔英文：C:\ARTDINK\Lde3\（避免中文 / 空格 / 過深層級）
  2. 套用官方 1.2 更新檔：解壓官方修正檔覆蓋遊戲資料夾（原版與更新版的版本資訊都標 1.0.8.2，不能用版本號判斷有沒有套用）
  3. NoCD 化：套第三之書保護光碟檔
  4. 解作業系統相容性：對應系統下載修正檔（通用 / XP / Win11）
  5. 輔助工具放遊戲資料夾內執行（舊站沿用的維護建議；個別工具以該工具附帶的說明為準）
  6. 登錄檔路徑用雙斜線：c:\\Program Files\\ARTDINK\\Lde3\\LDE3.EXE

[ FAQ · 6 個常見問題 ]

Q1. 安裝完跑遊戲變成「試玩版」？

原因：登錄檔內遊戲執行檔路徑沒寫對 / 系統升級後路徑失效。
解法：依作業系統下載對應修正檔執行。

Q2. 開啟遊戲提示「找不到光碟」？

原因：未套 NoCD 修正 / 光碟認證機制在新系統失效。
解法：套保護光碟檔。

Q3. 想直接攜帶玩不要安裝？

解法：用PortableLde3_tw1082r1.zip 可攜版。

Q4. 用修改器改完存檔，進遊戲數值沒變？

第三之書採自動儲存，遊戲進行中與結束時都會存檔（依遊戲附帶的說明檔）。先從選單〔遊戲〕選〔結束〕離開遊戲再改存檔；遊戲還開著就改檔，推定會被之後的儲存蓋回去。用本站瀏覽器版修改器時，改完要拿下載的檔案取代 usr/lde3s.le3。kkarthur 修改器 v0.4 的使用方式本站未核實，請以該工具的程式畫面為準。

Q5. 想使用角色管理與事件日期計算工具？

歷史第三之書管理員 1.03 / 1.06 內嵌第三之書包裝封面縮圖，壓縮檔註解另有功能說明與版本修正紀錄。

Q6. 為什麼推薦的工具多是 2007 到 2011 年的社群作品？

第三之書的社群工具多半完成於 2007 年到 2011 年之間，例如第三之書修改器 v0.4（2011-10-14）與 ELF v1.62（2011-11-25）。Morrowind / kkarthur / askacheng / anDY & aSKa STUDiO 等社群開發者貢獻的工具，本站只收錄、整理，沒有逐項實測比較。
