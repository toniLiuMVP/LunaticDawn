[ 主程式中的 14 個委託類型名稱 ]

遊戲主程式 Lde3.exe 內，接在「普通結束 / 無法達成 / 達成 / 實行中 / 發生」之後連續出現的 14 個名稱（推定是委託類型名稱）：

逃獄 / 通緝 / 討伐 / 試練 / 探索 / 驅退 / 打敵人 / 暗殺 / 奪回 / 強盜 / 走私 / 買東西 / 秘密出口 / 送貨

俠客遊 II 的 15 個任務類型名稱與這裡只有 5 個同名（探索 / 奪回 / 暗殺 / 強盜 / 送貨），這只是字面比對；說明檔另提到購物與救出委託，主程式的委託文字也有護衛與綁架，所以這 14 個名稱不一定涵蓋全部委託種類，對照見▸ 俠客遊 II vs 第三之書 系統對照。各類型的難度與報酬高低，本站尚未確認。

[ 在酒店接委託 ]

  • 每個城鎮都有酒店（附設旅館）。酒店的「委託」分頁集中了所有委託；選好委託按〔接受〕，按〔詳細〕可看內容，詳細視窗裡的〔聽取意見〕可以聽同伴對這件委託的看法。
  • 一覽表也會列出其他冒險者已經在做、你不能接的委託，可以接的標有「未」。
  • 可以同時接好幾件委託，活動地點集中在同一區域，比較不耗體力與金錢。
  • 達成後要在期限內回到接委託的那家酒店才能領報酬。
  • 報酬由隊伍全員平分，隊伍人數越多，每人分到的越少。
  • 情報店的〔委託關連〕可以查詢與已接委託有關的提示。
  • 隊伍選單的「委託一覽」可看已接委託的狀況：行動（執行中）、達成（還沒領報酬）、結束（已領報酬）。

依遊戲附帶的說明檔（hlp 資料夾）整理。

[ 新手與迷宮委託 ]

  • 說明檔建議剛出道的冒險者先接送貨或購物委託（購物與名稱表中的「買東西」是否同一類，本站未確認）；這個城鎮的酒店沒有時，可以到別的城鎮找。
  • 說明檔也提醒，一開始不要接驅退怪物的委託。
  • 要去迷宮時，可以順便接「驅退」「救出」這類委託，同時拿報酬。

[ 委託期限 ]

每件委託都有期限（遊戲日數），超過期限就無法回酒店領報酬。安排行程時注意：

  • 訓練所的訓練會連續佔用好幾天，期間不能離開，可能讓手上的委託過期。
  • 可以用第三之書日期計算器（Morrowind）規劃時程。
