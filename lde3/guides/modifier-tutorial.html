[ 安全修改 SOP ]

⚠️ 修改前務必備份

  1. 先結束遊戲：從選單〔遊戲〕選〔結束〕，會儲存目前的進度再離開。第三之書採自動儲存，遊戲內沒有儲存選單。
  2. 備份原檔：把遊戲資料夾內整個 usr/（存檔 lde3s.le3 所在）複製為 usr_backup/。同一個資料夾只能放一筆存檔，放第二筆會互相覆蓋，所以備份要放在別的資料夾。
  3. 先小幅修改測試：改一點就進遊戲確認讀得了，再做其他修改。
  4. 改壞了就還原：用 usr_backup/ 裡的存檔蓋回去。

「自動儲存」「同一資料夾只能放一筆存檔」與「遊戲進行中隨意移動存檔可能讓遊戲讀不到紀錄」都依遊戲附帶的說明檔（hlp 資料夾）。

[ 本站瀏覽器版修改器 ]

開啟：▸ 瀏覽器版修改器（純前端，存檔只在自己的瀏覽器內處理，不會上傳）

能做的事

  • 拖放或選擇 lde3s.le3，檢查檔頭並顯示檔案資訊
  • 在存檔中搜尋 Big5 中文字串出現的位置（本站實測的存檔在檔頭之後都找不到名稱字串，所以多半搜尋不到）
  • 產生區段熱圖，每 16 KB 顯示非零位元組的比例
  • 上傳另一份存檔（例如 lde3s.bak）做差異比對，列出不同的位元組（相鄰兩次存檔有 99.7% 的位元組不同）
  • 以十六進位編輯整個檔案，套用後下載修改過的存檔

目前做不到的事

本站實測的 6 份存檔，檔頭（0x00 到 0x6B）之後約 292 bytes 含存檔路徑與疑似系統位址，每台電腦、每次都不同，推定不是玩家資料；0x190 之後約 1 MB 的位元組分布接近均勻（熵 7.995 到 7.999 bits/byte），相鄰兩次存檔有 99.7% 的位元組不同，用 Big5、UTF-16、UTF-8 搜尋名稱字串都是 0 處，推定是壓縮或加密。本站沒有解開這一段，所以還沒有金錢、能力值等欄位的位置，不能像一般修改器那樣直接改數值，字串搜尋與差異比對也無法對應到欄位。想改數值請先看下方其他工具，並照上面的方式備份。

[ ELF v1.62 (Morrowind) ]

下載：Google Drive

ELF 是搭配遊戲一起執行的輔助工具，依附帶的 ReadMe 是 v1.62、2011-11-25。ReadMe 的版本說明提到的功能有：20 個道具儲物空間（第 20 個就是自宅的保管箱）、卡片與道具的陳列室、道具資訊顯示、戰場情報，以及吟遊詩人的時間修改。這些功能本站未逐項實測。

ReadMe 特別提醒：買房子時不要關閉 ELF。

[ 修改器使用建議 ]

  • 第一輪正常玩：體驗成長感跟挑戰
  • 卡關才用修改器：避免一開始就破壞樂趣
  • 修改幅度漸進：先小修，看遊戲反應，再大修
  • 保留 usr_backup/ 當對照：改壞了可以從備份還原
  • 重要進度另外備份：把當時的 usr/ 複製到另一個資料夾保存，避免只剩一份存檔
