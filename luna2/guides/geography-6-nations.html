📜 為什麼需要這篇

俠客遊 II 的世界分成 6 個國家、32 座城鎮，每國 3 到 8 座城鎮，每座城的設施都不一樣。 新玩家最常問的問題是：「我要在哪裡買武器、學魔法、找訓練、坐船？」這篇把 6 國的城鎮、設施與交通整理成速查表。

資料來源：國名、城鎮名、設施名、訓練項目名取自遊戲主程式 LUNA2.EXE 內的字串表（國名約在 0x3FC12 起、32 座城鎮在 0x3FD72 起、設施在 0x40088 起、訓練項目在 0x40128 起）；地下城與特殊地點名稱取自遊戲檔 DUNGNAME.ENC（共 80 處）。 各城鎮的設施、訓練項目、特產品、通行證與交通費用，依 1996 攻略書 PART 2「地理情報」的城鎮表整理；攻略書寫法與遊戲不同時以遊戲為準，並註明書上寫法。
⚖️ 特產品名稱、價格、交通費用等屬於玩家在遊戲內看得到的事實資訊；本站不轉載攻略書的解說文字與武器店、魔法屋的完整價目表。

🌐 6 國總覽

① 神聖吉札帝國

風貌：玩家一開始所在的國家（攻略書 P30）

城鎮（8 座）：歐德普克（有城）/ 薩爾茨海姆 / 德耳蒙特 / 路特卡得 / 多特貝克 / 漢斯莫特 / 諾爾豪鎮 / 巴林根

特殊地點（19 處）：地下迷宮 / 鍾乳洞 / 夢幻遺跡 / 空城 / 刑場遺跡 / 恐怖之城 / 療養院遺跡 / 祭場遺跡 / 短命洞窟 / 魔法研究所 / 虛幻廢墟 / 惡魔教會 / 建築物遺跡 / 收容所遺跡 / 謎之建築物 / 地下競技場 / 名譽之塔 / 地下大墳墓 / 武術大會遺跡

特色：歐德普克的設施最齊全，也是國內唯一教盜賊與物理系魔法的訓練所（攻略書 P65）；另一間訓練所在多特貝克。國內的路特卡得與多特貝克之間有船班。

特產品：玻璃裝飾品 / 貂皮 / 水彩壁畫 / 超高級酒

隱藏秘寶（5 件）：猛襲怪斧 / 聖釘頭鎚 / 太陽神神弓 / 巨人護手 / 歐利哈肯盾

② 敦津

風貌：街市帶有中國風情，遺跡與洞窟很多；可買到中級武器與防具，從神聖吉札帝國來的冒險者適合在此強化裝備（攻略書 P36）

城鎮（5 座）：江都（有城）/ 廣南 / 華安 / 天陽 / 仙醉鄉

特殊地點（13 處）：月下遺跡 / 水上遺跡群 / 虛幻之塔 / 鍾乳洞 / 嘆息洞窟 / 死亡地下遺跡 / 神之遺跡 / 迷幻森林 / 地下遺跡群 / 離宮遺跡 / 力之神殿 / 貴族建築物遺跡 / 審判神殿

特色：訓練所在江都與天陽，兩處都教格鬥；港口只在仙醉鄉，船開往日倭的鷹里。

特產品：絹 / 唐三彩 / 鴉片 / 漢藥

攻略書介紹的最強裝備：方天戟 / 頭突甲 / 刃狀甲 / 鷹爪腕 / 龍鱗腳

隱藏秘寶（5 件）：龍淵劍 / 如意棒 / 魔擲箭 / 逆鱗鎧 / 金剛雙拳

③ 穆哈爾帝國

風貌：國土廣大，但河川與綠地很少，大半是沙漠；遺跡與洞窟多，任務常要長途跋涉（攻略書 P40）

城鎮（6 座）：阿薩拉姆（有城）/ 烏魯姆 / 埃耳卡拉亞 / 穆沙利卡 / 嘉哈 / 索爾哈拉亞

地下城（17 處）：古迷宮 / 礦坑遺跡 / 信徒之墓 / 試練迷宮 / 大學院遺跡 / 象牙城 / 大宮殿 / 死亡之地 / 廢坑 / 魔術研究所 / 地下神殿 / 地下審判迷宮 / 水上神殿遺跡 / 湖之廢墟 / 山腰大洞窟 / 訓練場遺跡 / 不流瀑布洞窟

特色：訓練所在阿薩拉姆與索爾哈拉亞；港口在埃耳卡拉亞，船開往馬尼卡帕王國的里歐庫列歐。阿薩拉姆的魔法屋有賣守護娃娃（25,000G）。

特產品：香料 / 絨毯 / 象牙 / 麻藥

攻略書介紹的最強裝備：彎刀 / 牛角盔 / 鱗甲 / 刺刀肘套 / 刺針鞋 / 刺盾

隱藏秘寶（5 件）：火炎神劍 / 火燄神杖 / 水帝之槍 / 穿刺擊 / 飛翅靴

④ 日倭

風貌：四面臨海、國土分成四塊的小國，解決事件時常要坐船；武器店賣得到最強的刀劍「胴太貫」，也有用劍的高手，攻略書說想成為劍豪的角色不可錯過（攻略書 P46）

城鎮（5 座）：紫波羅（有城）/ 鷹里 / 鹿谷 / 龍諸野 / 額隈（攻略書作「額限」）

地下城（12 處）：龍地 / 詛咒迷宮 / 博物館遺跡 / 遙遠洞窟 / 地下墓地 / 湖下迷宮 / 大洞窟 / 混沌遺跡 / 黑鷲城 / 迷幻水路 / 地下神殿 / 命運神殿

特色：國內有兩條船班（紫波羅 ↔ 龍諸野、額隈 ↔ 鹿谷），鷹里另有船開往敦津的仙醉鄉；訓練所在紫波羅與龍諸野；龍諸野的武器店賣忍刀、鎖鎌、手裡劍。

特產品：松茸 / 煙草 / 漆碗 / 玳瑁

攻略書介紹的最強裝備：胴太貫 / 星兜 / 黑鋼體 / 鉤爪 / 蹴打甲

隱藏秘寶（5 件）：神仙劍 / 妖刀村正 / 金太郎大鉞 / 希希洛卡奈帽 / 勾玉戒指

⑤ 馬尼卡帕王國

風貌：強力的武器與防具很多，攻略書建議來這裡充實裝備；土地大多被密林圍繞、河川多，路途遙遠，要帶足食物（攻略書 P50）

城鎮（5 座）：葉斯塔利貝拉（有城）/ 聖米哥 / 珊塔爾加 / 埃爾門德 / 里歐庫列歐

地下城（12 處）：真實遺跡 / 地下墓地 / 留置場遺跡 / 犧牲品島 / 地下遺跡 / 虛神神殿 / 愚者遺跡 / 湖上廢墟 / 狂熱信徒遺跡 / 神殿遺跡 / 隱形遺跡 / 魔神樹之塔

特色：訓練所在葉斯塔利貝拉與聖米哥；兩個港口，里歐庫列歐的船開往穆哈爾帝國的埃耳卡拉亞，埃爾門德的船開往芙庫基歐的庫列蒙迪。

特產品：大麻 / 豹皮地毯 / 水銀 / 蜂王乳

攻略書介紹的最強裝備：銀斧 / 虎頭盔 / 皮衣 / 皮手套 / 膝釘

隱藏秘寶（5 件）：光輝之斧 / 托迪姆斧 / 破岩棒 / 帕卡爾守護盔 / 兀鷹之鎧

⑥ 芙庫基歐

風貌：全世界唯一有教精靈系魔法訓練所的國家，居民身上長著翅膀；多數武器與裝備有優秀的魔法抵抗力，攻略書建議僧侶系與戰士系角色前來（攻略書 P54）

城鎮（3 座）：帕爾魯吉（有城）/ 庫列蒙迪 / 隆努

地下城（7 處）：儀式之塔 / 謎之採掘場 / 廢墟群 / 眾妖精廢墟 / 不動之迷宮 / 謎幻墳墓群 / 湖上之屋遺跡

特色：精靈系魔法只有帕爾魯吉的訓練所教；港口在庫列蒙迪，船開往馬尼卡帕王國的埃爾門德。

⚠️ 船期：攻略書 P54 寫「四、八、十二月船不出航」，P65 卻寫「從埃爾門德出航的船只在 4、8、12 月」，兩處說法相反，本站未實測。

特產品：曼陀羅華 / 豎琴 / 萬能解毒劑 / 秘密軟膏

隱藏秘寶（5 件）：菲恩瑪庫魯魔槍 / 克拉普弓 / 風之靴 / 米斯里魯盾 / 隱形戒指

各國隱藏秘寶的類型與數值見武器系統 + 玩家成長路徑的「六國隱藏秘寶（30 件）」表；32 座城鎮各自的設施與交通也列在同一篇。 遊戲主程式的城鎮表依國家分組排列（神聖吉札帝國 8、穆哈爾帝國 6、敦津 5、日倭 5、馬尼卡帕王國 5、芙庫基歐 3），和攻略書的城鎮歸屬一致；DUNGNAME.ENC 的前 64 處地下城也依同一國家順序排列，後 16 處是各國追加的地點。

📖 攻略書的路線建議

以下是攻略書 PART 2、PART 3 提到的方向，本站未逐一實測：

  1. 起點：神聖吉札帝國歐德普克（設施齊全，初期訓練多在這裡）。攻略書建議先在歐德普克、多特貝克、薩爾茨海姆一帶接送貨與護衛任務，較遠的諾爾豪鎮、巴林根先不接（P63）
  2. 元素系魔法：多特貝克的訓練所；歐德普克沒有直達的驛馬車，要經過德耳蒙特（P65）
  3. 強化裝備：敦津的中級武器與防具（P36）
  4. 找武器：攻略書建議依技能找強力武器，劍技到日倭（胴太貫在紫波羅、鷹里的武器店）、格鬥到敦津、弓到芙庫基歐、其他技能到馬尼卡帕王國（P59）
  5. 精靈系魔法：芙庫基歐帕爾魯吉，路線見上方通行證說明（P65）

攻略書 P59 的「最好的裝備組合」：武器利刃飛盤（庫列蒙迪）、頭部牛角盔（烏魯姆）、身體貝赫摩斯鎧（帕爾魯吉）、手部鷹爪腕（廣南、華安）、腳部龍鱗腳（廣南）、盾龍鱗盾（庫列蒙迪）。
