📜 必殺技系統概要

俠客遊 II 的必殺技系統由 HISSATSU.MST（位於 遊戲資料夾/P/HISSATSU.MST）控制。 本站 2026 逆向了它 32 筆記錄的主要欄位（部分欄位意義尚未解讀），招式名稱取自遊戲檔 MGCNAME.ENC 第 80 至 111 號，記錄 N 對應第 80 + N 號。

必殺技與武器類別：HISSATSU.MST 前 16 筆（records 0-15）各帶一個武器類別碼（byte 3，0 至 7），每個類別碼有兩筆，同一類別中第二招的威力比第一招高。 推定每種武器類別對應一組必殺技，類別碼對應哪一種武器的依據見下方說明；發動條件、STM 消耗與相對一般攻擊的倍率都尚未在遊戲內實測。

⚔️ 8 個武器類別碼的必殺技

① 秘劍真空切 / 秘劍月輪亂舞

類別碼 0：依稱號排列推定為刀劍類
第一招（秘劍真空切）b1（推定 STM）90
第一招威力300
第二招（秘劍月輪亂舞）b1（推定 STM）110
第二招威力450
HISSATSU.MST records0（第一招） / 1（第二招）

社群攻略記錄的 STM 消耗是 90 與 110，與這兩筆的 b1 相同。

社群攻略把這兩招標為區域攻擊，STM 消耗 85 與 115，與這兩筆的 b1 相同。

社群攻略把這兩招標為個人攻擊（烈風旋棍連周圍也會打到），STM 消耗 88 與 110，與這兩筆的 b1 相同。

④ 破魔貫槍 / 神槍閃烈破

第二招威力 465，是 8 組中最高。社群攻略記的 STM 消耗是破魔貫槍 88（b1 為 92）、神槍閃烈破 118（與 b1 相同）。

社群攻略把疾風連擊弓標為個人攻擊、天空迅雷弓標為敵方全體，STM 消耗 84 與 108，與這兩筆的 b1 相同。第一招 b1 為 84，是類別碼 0 至 5 這六組中最低。

第一招威力275
第二招（爆裂破裂彈）b1（推定 STM）104

社群攻略的招式順序與資料檔相反（先寫爆裂破裂彈），依招式名稱對照 STM，翔空飛燕斬 87、爆裂破裂彈 104，都與 b1 相同。第一招威力 275，是類別碼 0 至 5 這六組中最低。

⑦ 氣功飛翔拳 / 氣功極身突

第一招（氣功飛翔拳）b1（推定 STM）60
第一招威力100
第二招（氣功極身突）b1（推定 STM）110
第二招威力400
HISSATSU.MST records12（第一招） / 13（第二招）

社群攻略記的氣功飛翔拳 STM 消耗是 66（b1 為 60），氣功極身突是 110（與 b1 相同）。第一招 b1 為 60，是 8 組中最低，威力只有 100。

⑧ 虛空轉移術 / 蟬蛻之術

類別碼 7：依稱號排列推定為閃躲類
第一招（虛空轉移術）b1（推定 STM）70
第一招威力100
第二招（蟬蛻之術）b1（推定 STM）95
第二招威力230
HISSATSU.MST records14（第一招） / 15（第二招）

社群攻略把這兩招列在閃躲高手底下，只提到蟬蛻之術使用後身體會變成透明，沒有寫 STM 消耗。第一招威力 100（與氣功飛翔拳並列最低），第二招威力 230 是 8 組中最低；威力欄對這一組的意義未確認。

類別碼與武器種類：8 個類別碼對應哪一種武器，是依下列兩項資料推定的，還沒有在遊戲內驗證：
  • 遊戲檔 CALLNAME.ENC 第 192 至 199 號的稱號依序是刀劍高手、使斧高手、棍棒高手、使槍高手、弓箭高手、擲矛高手、格鬥高手、閃躲高手，與這 8 組招式的順序一致；MGCNAME.ENC 第 80 至 95 號的招式名兩兩一組，排列方式也與第 96 至 111 號（記錄 16 至 31 的怪物必殺技，已用攻略書核對）相同。
  • 站上的社群攻略〈俠客遊 II 主攻略〉把這 16 招依稱號分成 8 組，並記下其中 14 招的 STM 消耗；依招式名稱對照，有 12 招與 HISSATSU.MST 記錄 0 至 13 的 b1 相同，不合的是破魔貫槍與氣功飛翔拳。
LUNA2.EXE 的 0x03FCC2-0x03FD07 另有 8 個必殺技系統名稱（拔刀波斬流、暴棍撲術、直棍撲術、真槍貫術、爆矢眼弓法、剛投爆石、波動六骸法、斷強破防），與各武器類別的對應未確認，本頁不把它們當作記錄的名稱。

📊 威力與 b1（推定 STM）對照

power / b1 比（b1 推定為 STM 消耗，尚待遊戲內實測）： - 秘劍真空切：300/90 = 3.33× - 秘劍月輪亂舞：450/110 = 4.09×（最高） - 衝擊斬波斧：310/85 = 3.65× - 剛斧大瀑布：460/115 = 4.00× - 神槍閃烈破：465/118 = 3.94× - 氣功飛翔拳：100/60 = 1.67×（b1 最低，威力與虛空轉移術並列最低） - 虛空轉移術：100/70 = 1.43×

建議： 以 b1 推定值換算，類別碼 0 至 5 這六組的第二招威力 / b1 比約比第一招高 10% 至 23%，b1 多 17 至 30；氣功飛翔拳與虛空轉移術的威力只有 100。 玩家初期 STM 不高時優先用第一招；STM 練上去後切換第二招（玩法參考）。

b1 欄位（推定 STM）分布：

  • 12 筆（id 16-21, 26-31）：b1=60，威力 250-500，byte 2-3 = 0xFFFF（不屬於 8 個武器類別）
  • 4 筆（id 22-25 = 4 元素精靈）：b1=15 或 10，威力 100

怪物資料庫目前沒有必殺技欄位；哪一隻怪物使用哪一筆，請看必殺技資料庫，那裡有 32 筆記錄全表與怪物對照。

🎯 玩家路線建議

以下是玩法參考，b1 當作 STM 消耗是推定值。

  1. 新手期：用每類的第一招，類別碼 0 至 5 這六組的第一招威力 275-310（b1 84-92）
  2. 中期：STM 練高後切換第二招（第二招威力 230-465，類別碼 0 至 5 這六組為 400-465）
  3. STM 較高的角色：類別碼 0 至 5 這六組第二招的威力 / b1 比約 3.8 至 4.1，可多用第二招
  4. STM 較低的角色：氣功飛翔拳（第一招）的 b1 最低（60），但威力只有 100；社群攻略記的 STM 消耗是 66
  5. 對 boss：用第二招，並到怪物資料庫查防砍 / 防刺 / 防敲，挑較低的攻擊方式

🔬 技術細節（給逆向有興趣的人）

HISSATSU.MST 結構（每 record 36 bytes）：

byte 0: record id (0-31) byte 1: b1，推定為 STM 消耗（待遊戲內實測） byte 2: 第一招 0x52 / 第二招 0x5F（records 16-31 = 0xFF） byte 3: 武器類別碼 0-7（records 16-31 = 0xFF） byte 4-5: u16 LE power（威力值） byte 6-7: u16 LE，意義尚未解讀 byte 8-9: u16 LE，數值與威力相近，意義尚未解讀 byte 10-15: 意義尚未解讀 byte 16: records 14-17 有值，其餘 0xFF，意義尚未解讀 byte 17: ★ 怪物 ID（records 16-31 對應 MONSTER.DAT index） byte 18-35: 意義尚未解讀（後段多為 0 或 0xFF）

必殺技資料（HISSATSU.MST）的解析程式沒有公開；怪物資料的交叉驗證程式見 tools/extract/cross_validate_monsters.py。
