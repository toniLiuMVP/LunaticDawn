📜 戰鬥系統概要

俠客遊 II 戰鬥系統是 1996 年同類 RPG 中複雜度最高的之一，由 6 大子系統組成：

  1. 8 大屬性（力 / 智 / 靈 / 敏 / 直 / 魅 / 體 / 精），影響所有 stat checks
  2. 15 技能熟練度（劍 / 斧 / 棍棒 / 槍 / 弓 / 格鬥 / 投擲 / 迴避 / 盜賊 / 野營 + 5 系魔法，順序依存檔 0x78-0x86）
  3. 5 系魔法（物理 / 元素 / 神聖 / 暗黑 / 精靈）
  4. 8 類必殺技（秘劍真空切 / 衝擊斬波斧 等；每類兩招，類別碼對應的武器為推定）
  5. 6 種恐懼症 + 沒有（野獸 / 魔獸 / 魔法生物 / 巨人 / 不死生物 / 幽靈），建立角色時選的弱點
  6. 3 種攻擊方式（砍 / 刺 / 敲）+ 對應 3 軸防禦

⚔️ 3 種攻擊方式

LUNA2.EXE 偏移 0x40022 起的攻擊類型字串只有「沒有 / 砍 / 刺 / 敲」；物品資料 ITEMDATA 的攻擊類型欄也只用這三種（456 筆物品中砍 39 筆、刺 46 筆、敲 66 筆，其餘為無）。怪物資料有對應的三個防禦欄位。

攻擊方式怪物對應的防禦欄（MONSTER.DAT）
砍防砍（byte 0x40）
刺防刺（byte 0x42）
敲防敲（byte 0x44）
戰術選擇（玩法參考）：到怪物資料庫查目標的防砍 / 防刺 / 防敲，挑三者中最低的那一種攻擊方式；武器的攻擊類型可在物品資料庫查到。

📊 戰鬥系統 binary 對照

玩家 / NPC 角色（LUNACHAR.SAV byte offsets）

0x36-0x3D: 8 大屬性 (1 byte each)，力 / 智 / 靈 / 敏 / 直 / 魅 / 體 / 精 0x3E-0x45: 8 屬性上限 (1 byte each) 0x78-0x86: 15 技能熟練度 (1 byte each, 0x87 為空隙) 0x88: 物理系魔法 (u16 LE bitfield) 0x8A: 元素系魔法 (u16 LE bitfield) 0x8C: 神聖系魔法 (u16 LE bitfield) 0x8E: 暗黑系魔法 (u16 LE bitfield) 0x90: 精靈系魔法 (u16 LE bitfield) 0x92: 武技 (u16 LE，可裝備到 0xFFFF 全武技)

怪物（MONSTER.DAT byte offsets）

0x14: HP (u16 LE) 0x16: MP (u16 LE) 0x18: STM 體力 (u16 LE) 0x1A: 等級 Lv (u16 LE) 0x24: 經驗值 (u16 LE) 0x3E: ATK 攻擊力 (u16 LE) 0x40: 防砍 (u16 LE) 0x42: 防刺 (u16 LE) 0x44: 防敲 (u16 LE)

🎮 戰鬥中的「喊叫」指令（說明書 P150）

「喊叫」是向部隊同伴打招呼、指示行動：可以選一個人下令，也可以按〔全體人員〕向全員下令，兩者能下的指令內容多少有些不同。可下的指示如下：

指示機制
解救叫某人去援助另一名同伴：對方接受的話，就開始攻擊敵人，替那名同伴掩護
治療叫某人用魔法治療，接受的話就使用指定的治療魔法；只能對個人，無法對全體
跳跑（撤退）戰鬥中讓某人撤退；向全員指示撤退時，自己也要撤退
攻擊敵人叫某人攻擊指定人物；指定〔全體人員〕時全隊一起攻擊同一個敵人，但攻擊方式不指定，同伴可能用魔法攻擊
使用道具讓此人使用自己帶的道具，只能用在個人，不能用於全隊

💡 重要機制：地下城內若門上鎖，物理系魔法可以打開鎖（不必依賴鑰匙 / 盜賊技能，說明書 P132）。

🗺 戰鬥地圖 UI（說明書 P145）

  • 畫面右下方有縮小的戰鬥領域全部地圖（〔戰鬥地圖〕）
  • 四角框之中的部份 = 上方畫面當前顯示的部份
  • 戰鬥地圖外側看起來像牆壁的東西，就是牆壁
  • 從地下城進入戰鬥時，戰鬥場所的地形取自地下城的地形

位置移動控制：拉動綠色方框移動戰鬥地圖，定位後按滑鼠左鍵；地圖上有 8 個方向箭頭，按一下即向該方向移動。

⚡ 戰鬥流程 & 行動順序

以下流程中，標明攻略書出處的是書上的說明；其餘是推定，尚未在遊戲內驗證。

① 敏捷

敏捷屬性（byte 0x39）影響戰鬥中的移動力與迴避技能熟練度（攻略書 PART 1）。

② 命中判定（推定）

武器命中率 + 玩家「直覺」（byte 0x3A）+ 武器技能熟練度，推定共同決定命中率。

建議：選一兩種武器類別專心練熟練度。

③ 傷害計算（推定）

武器攻擊力與屬性加成，扣掉敵人對應的防禦（防砍 / 防刺 / 防敲），推定為最終傷害。

必殺技的 power 值（HISSATSU.MST byte 4-5）推定與必殺技傷害有關。

④ STM 消耗

戰鬥中 STM 會慢慢減少，集中力與忍耐力隨之下降；STM 變成 0 之後，HP 會逐漸降低（攻略書 PART 1）。

必殺技的 b1 欄位（每類第一招 60 至 92、第二招 95 至 118）推定為 STM 消耗量。

⑤ MP 消耗

法術的 MP 消耗是 10 至 200（MGCDATA）。MP 為 0 時只是無法施法，沒有其他影響（攻略書 PART 1）。

⑥ 狀態異常

中毒 / 失明 / 麻痺 / 沈默 / 石化等，可用對應道具或神聖系魔法解除。

攻略書記載終局 boss 的攻擊都帶有特別效果，準備充足的解除道具。

👹 恐懼症與額外點數（攻略書 PART 1 表三）

恐懼症是建立角色時選的弱點：戰鬥中遇到自己害怕的怪物時無法發揮 100% 實力，但選了弱點可以換到較多的額外點數。同伴之間若沒有相同的弱點，可以互相補位。各分類包含哪些怪物，請見怪物攻略整合篇。

弱點額外點數

野獸恐懼症100
魔獸恐懼症98
魔法生物恐懼症95
巨人恐懼症87

🛡️ 防禦戰術

① 物理防禦

  • 頭部護具：流星盔 / 羽飾盔 / 名甲 / 鐵甲（防砍 / 防敲為主）
  • 身體防具：鋼甲 / 鎧甲 / 厚皮甲 / 軟皮甲（防砍 / 防刺平衡）
  • 手部護具：鎧手套 / 護腕 / 鐵拳（防敲為主）
  • 腿腳護具：鏈甲靴 / 強盜靴 / 皮靴（防刺）
  • 盾類：方盾 / 圓盾 / 龍鱗盾 / 銳刃盾（全方位防禦）

② 七系魔法上限

物品資料有 7 個「七系魔法上限」欄位（物理 / 炎熱 / 冷卻 / 電光 / 神聖 / 暗黑 / 精靈），數值見物品資料庫；這些欄位與魔法防禦的實際關係尚未驗證。

③ 狀態異常道具（效果依物品名稱推定）

  • 解毒石，解除中毒
  • 解沈靜符，解除沈默
  • 防盲目鏡片，防止失明
  • 守護娃娃，效果未確認

④ 守護法術（神聖 / 物理系）

  • 祝福術，提高隊伍 STM
  • 護盾術，提高一名角色對武器攻擊的防禦

※ 封魔術（物理系）不是全隊防護法術：它只對單一目標施放，目標身上的所有魔法（含治療魔法）都會失效，目標本身也無法施法（攻略書魔法附冊）。比較適合拿來封鎖敵方施法者。

💀 boss 戰術整理

對應怪物攻略整合篇的 boss 群（id 122-127 全 Lv 50）：

以下為玩法參考。

提斯卡托（HP 最高）

HP 999 / ATK 170 / 魔法數 21

  • 用「沈默術」或「封魔術」封鎖施法（物理系）
  • 必殺技第二招輪流發動（第二招 power 230-465）
  • 4 召喚獸全用（伊弗利朵 / 琴恩 / 克拉肯 / 貝希摩斯）
  • 準備大治療法（神聖系）+ 狀態異常解除道具

魔王阿迦魯瑪

HP 788 / ATK 155 / 魔法數 21

  • 會用魔法，可用沈默術或封魔術封鎖施法
  • 攻略書魔法附冊記載除魔大法的對象是不死生物、鬼魂等敵人；魔王屬惡魔類，不在所列對象之中
  • 裝備攻略書「特殊寶物類」武器（火炎神劍）
  • 同行 NPC 配置 1 戰 1 法 1 治療

共工 / 酒吞童子（中華 / 日式神話）

HP 790-795 / ATK 160-162 / 魔法數 3 / 0

  • 攻略書標示共工會用魔法、酒吞童子不用
  • 查兩者的防砍 / 防刺 / 防敲，挑較低的攻擊方式
  • 高威力必殺技第二招（例如神槍閃烈破 power 465）

貝利亞 / 帕茲斯（西亞神話）

HP 792-800 / ATK 150-152 / 魔法數 21

  • 魔法系 boss，先用沈默術或封魔術
  • 暗黑系反制（驟死術 / 石化術）
  • 攻略書記載兩者的攻擊帶有沈默、盲目等特別效果，準備解沈靜符 / 防盲目鏡片

📈 戰鬥能力提升路徑

以下為玩法參考。

  1. 新手期：練 1-2 種武器類別到熟練度 30+，敏捷 / 力量提到 12+
  2. 初期：學物理系魔法（照明 / 開鎖 / 索敵 / 護盾），探索 + 防禦兼顧
  3. 中期：選元素系（攻擊）或神聖系（治療）為主魔法路線
  4. 中後期：必殺技第一招 + 強化武器到 16-24 級
  5. 後期：必殺技第二招 + 強化武器 32 級 + 暗黑系狀態異常
  6. 終局：5 系魔法全會 + 4 召喚獸 + 高階武器（火炎神劍 / 神仙劍 / 火燄神杖）

🔬 戰鬥的其他說法（未實測）

以下是玩家之間流傳的經驗性說法，本站尚未在遊戲內驗證：

狀態異常持續性：中毒會持續扣 HP；麻痺會停止行動一段時間；石化需要道具或魔法解除。

STM 回復：戰鬥外慢慢回復，在旅店休息可補回。

同行 NPC：會自動戰鬥，必要時用指令介入。
